# 宝可梦重装上阵 简体中文汉化（Pokémon Reloaded 中文补丁）

西班牙作者 F3R 的同人游戏 **Pokémon Reloaded / Proyecto Reloaded**（GameMaker 8 制作）的简体中文汉化。

- **对应游戏版本：The Last Beta 1.9.2.2**（`Proyecto Reloaded The Last Beta 1.9.2.2 Full.exe`，SHA-256 `772d5d45…bf07630`）
- **译名标准：宝可梦官方简体中文**。宝可梦、招式、特性、道具、图鉴、人物都以官方译名为准（数据来自 [PokeAPI](https://pokeapi.co/) 和 [神奇宝贝百科](https://wiki.52poke.com/)，详见下文「译名从哪来」）；游戏原创的宝可梦、地名、人物按官方风格自译，并在术语表里标注「自译」。
- 能直接用官方原文的地方都用了官方原文，比如招式说明、特性说明、图鉴分类、图鉴说明。图鉴说明会先找出作者原文拼用了哪几版官方图鉴，再拼接对应版本的官方中文。
- 本仓库**不含游戏本体和任何原作素材**。游戏请到作者官方博客下载：<https://pokemon-reloaded.blogspot.com/>；国内打不开博客的话，可以用夸克网盘下作者原包：<https://pan.quark.cn/s/cd3cc696bf93>

## 安装方法（Windows）

1. **下载游戏**：在作者博客下载 *The Last Beta 1.9.2.2 Full* 并解压，比如解压到 `D:\Games\Proyecto Reloaded`。国内打不开作者博客的话，用[夸克网盘](https://pan.quark.cn/s/cd3cc696bf93)下（作者原包，没改过）。
2. **下载补丁**：下载最新的 **`PokemonReloaded-zh-patch.exe`**，三个地方内容一样，任选一个：
   - [GitHub 发布页（Releases）](https://github.com/1596941391qq/pokemon-reloaded-zh/releases)
   - [夸克网盘](https://pan.quark.cn/s/1608d8f5e7a3)（国内高速下载，打开最新版本的文件夹）
   - [爱发电](https://afdian.com/a/pokerogues)（下载免费，愿意的话可以自愿赞助）
3. **打补丁**：把它放进游戏文件夹（和游戏的 exe 放在一起），双击运行，约 10 秒完成，看到「完成！」后按回车关闭。不用装 Python 或其他东西。
   - 补丁没有数字签名，Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
   - 也可以不放进游戏文件夹：双击后把游戏文件夹拖进窗口，按回车。
4. **开始游戏**：直接运行游戏 exe，默认就是简体中文。也可以在游戏的语言选项里切回英语或西语。

**游戏里汉字显示不出来、全是乱码？** 多半是补丁没打完整：打补丁时游戏还开着，或者被杀毒软件（360、火绒等）拦了。先关掉游戏，下载最新版补丁再双击一次；窗口里提示被拦的话，在杀毒软件里允许补丁（或把游戏文件夹加入信任）后再双击。zh-20261110 起，补丁改不了游戏程序时什么都不动，不会再出现「语言是中文、程序还是原版」的情况。

**存档被清空、读档提示「存档已损坏」？** 游戏自带防修改检测，zh-20261112 之前的补丁会被它误判，每进一个房间都有小概率清空全部存档。请更新到最新版；已经清空的存档找不回来。建议隔一阵备份一次游戏目录下的 `data\partidas` 文件夹。

**对话着突然没字了，空的对话框一直挂着、关不掉？** zh-20261112b 及更早的补丁在约 3% 的句子上会这样（比如研究所选初始宝可梦时大木的第一句），请更新到最新版。没更新之前，按 F5 等会弹出提示框的键可以让画面恢复。

**读档后变成英文或西语？** 请更新到最新版。zh-20261113b 起，不管是标题画面读档，还是游戏里按 F6、从菜单读档，都用标题画面选的语言，不会被存档改回英文。zh-20261113 在游戏里按 F6 或从菜单读档会变成西语；更早的版本读旧存档会变回英文。临时办法：在游戏的选项里把语言切回简体中文。

会写 Python 的也可以用源码打补丁：本页右上角 **Code → Download ZIP**，然后 `python patch.py "D:\Games\Proyecto Reloaded"`（或双击 `安装中文补丁.bat`），需要 Python 3.8+，不用第三方库。

补丁会把原版 exe、`lan.txt`、`config.ini` 备份到游戏目录下的 **`原版备份`** 文件夹。之后每次打补丁都以这份备份为底重新生成，所以译文更新后再运行一次即可，不会越改越乱。

**恢复原版**：把 `原版备份` 里的三个文件拷回原处（exe 放回游戏根目录，另外两个放回 `data\text\`），再删掉 `data\text\zh` 文件夹。

## 译名从哪来（参考资料）

只认宝可梦官方简体中文。官方有的直接用，官方没有的才自译，并在术语表里写明理由。

| 内容 | 参考的官方资料 | 怎么用 |
|---|---|---|
| 宝可梦名、招式名、特性名、道具名 | [PokeAPI](https://github.com/PokeAPI/pokeapi) 数据库（整理自官方游戏数据）里的官方简体中文名：`pokemon_species_names`、`move_names`、`ability_names`、`item_names` 四张表 | 按英文名对上就直接用 |
| PokeAPI 还没收录简中的新内容：268 号以后的特性、920 号以后的招式 | [神奇宝贝百科](https://wiki.52poke.com/) 的特性列表、招式列表 | 从百科补上官方译名 |
| 招式说明、特性说明 | PokeAPI 里的官方简中说明：`move_flavor_text`、`ability_flavor_text` | 作者原文和官方英文或西语说明对得上，才用官方中文。《剑／盾》里「无法使用的招式」那句占位说明不用 |
| 图鉴分类（如「种子宝可梦」） | PokeAPI `pokemon_species_names` 里的分类 | 作者的英文分类和官方一致才用 |
| 图鉴说明 | PokeAPI 官方图鉴文字 `pokemon_species_flavor_text`。用的是有官方简中的 8 个版本：《太阳／月亮》《究极之日／究极之月》《Let's Go！皮卡丘／伊布》《剑／盾》 | 作者常把几个版本的图鉴拼成一条。先拿西语原文去匹配各版本的官方西语图鉴，找出拼了哪几条，再按原顺序拼上同版本的官方简中 |
| 官方人物、其他地区的道馆徽章 | 神奇宝贝百科的人物页、徽章页 | 逐个核对，比如 Lyra = 琴音、Sycamore = 布拉塔诺博士 |
| 通用说法：道馆馆主、四天王、精灵球、宝可梦中心、海洋队等 | 官方游戏的简中用语，对照神奇宝贝百科 | 写在 [`translations/STYLE.md`](translations/STYLE.md) 里，译者照着用 |
| 超级进化、超极巨化、招式学习器、原创进化石 | 套官方命名规则 | 超级妙蛙花、超极巨化妙蛙花、秘传学习器01 居合斩、皮卡蓝进化石 |
| 游戏原创的宝可梦、地名、人物、道具 | 没有官方译名，按官方风格自译 | 术语表里标「自译」并写明理由，比如星辰地区的城镇按星宿译：Spica = 角宿市 |

- PokeAPI 的简中数据里混进了几个繁体字和日文中点（「負」「纏」「轍」「・」），已统一改成「负」「缠」「辙」「·」。
- 译文里的专有名词由 `tools/term_check.py` 逐条对照术语表检查，防止同一个名字前后译法不一。

## 参与翻译

译文在 `translations/<文件>.json` 里，每条形如 `{"id": 行号, "en": 英文, "es": 西语, "zh": 中文}`，只改 `zh` 一栏。规范见 [`translations/STYLE.md`](translations/STYLE.md)。改完运行：

```
python tools/check_part.py translations/txt_dialog.json txt_dialog   # 检查控制符、编码
python tools/term_check.py                                         # 检查官方译名是否一致
```

## 更新流程（游戏出新版本时）

Mac 上的 Claude 桌面版有个定时任务「宝可梦重装上阵 · 查新版本」，每天上午 10 点多跑一次 `check`（桌面版开着才跑，关着的话下次打开时补跑）。发现新版本后，它会在那次定时任务的对话里报出文件名、来源和大小，**hacking 同意后才下载**，然后按下面的步骤做完：

```
python3 -I tools/update.py check              # 1. 查作者博客：有新版本时退出码 10，列出文件名、来源（MEGA / gofile）、大小，不下载
python3 -I tools/update.py fetch <版本>        # 2. hacking 同意后才跑：下载到 work/update/<版本>/download/（空目录），
                                              #    只解出根目录的 exe、说明 txt 和 data/text，不运行任何 exe
python3 -I tools/update.py diff <版本>         # 3. 导出新版文本，和旧版逐行对齐，写出 待翻行.md、todo/、prompts/
                                              #    每个 prompts/batchN.md 派一个翻译子代理，译文交到 parts/
python3 -I tools/update.py merge <版本>        # 4. 旧译文搬到新行号，合并新译文，跑 check_part 和 term_check
python3 -I tools/update.py build <版本>        # 5. 用新版试打补丁（只读写文件），复查改过的 exe
python3 -I tools/update.py release <版本>      # 6. 补 patch.py 的 KNOWN，改 README 版本号，刷新进度表，提交并推送
python3 -I tools/update.py status             # 随时看进行到哪一步
```

- **怎么对比**：每个文件按英文原文逐行对齐（`difflib`），所以插行、删行造成的整体错位也能对上。每行分成五种：原文没变（沿用译文）、改动（原地改句子，或和旧行相似度 ≥ 0.6）、只改了西语、新增、和旧版别处某行一字不差（直接沿用那行的译文）。
- **只派新增和改动的行**。改动的行会带上旧原文和旧译文，译者在旧译文基础上改，用词保持一致。还没开始翻的文件（比如考试题）只列在清单里，不派单。没翻到的行显示英文，不影响游玩。
- **旧版还能用**：译文按新版行号保存，KNOWN 里保留旧版的 SHA-256。旧版打补丁时按英文原文找回译文，只有改过的句子会显示英文。`build` 会报出旧版能显示多少条中文。
- **把关的地方**：
  - `fetch` 之前必须经过 hacking 同意。
  - 第一次 `merge` 时，如果 `translations/` 有没提交的改动，或者 `work/parts/` 里有按旧行号写、还没合并的译文，就停下，免得冲掉别的会话正在翻的内容。旧译文会先存一份快照，重跑 `merge` 不会越合越乱。
  - `build` 发现新版 exe 里补丁要改的代码变了，就停下等人看。
- **其他情况**：自动下载失败时，可以手动下载，再用 `fetch <版本> --from 压缩包` 接着走。决定不跟某个版本时，用 `decline <版本>`，之后不再提醒。
- **回归测试**：`python3 -I tools/fake_version.py game <输出目录>` 会用现有版本造一个假的 1.9.2.3，包含插行、删行、改句、只改西语、新增道具、未开翻文件的改动，再附一份假的博客订阅。之后在仓库的临时克隆里按上面的步骤走一遍即可（`check --feed <输出目录>/feed.json`、`fetch 1.9.2.3 --from <压缩包>`，最后 `release --no-push`）。`work/update/` 不进仓库。

## 原理（给想改代码的人）

- 游戏文本在 `data/text/<语言>/*.dll`，其实是纯文本，每个字节用一张固定的替换表加了密（游戏脚本 `ValuesAdjustment6`）。`tools/rtext.py` 负责解密和加密。
- GameMaker 8 自带的字体只有 256 个字符，显示不了中文。所以补丁会改游戏 exe：先按 GM8.0 的格式解密数据块，再把所有画字函数（`draw_text`、`string_width` 等）换成自己写的 `zh_*` 版本（见 `patch/gml/`），最后塞进两张中文像素字图集（译文用到的字加上 GB2312 全部常用字，方便玩家起中文名），并按原算法重新加密。这部分代码在 `tools/gm8_repack.py` 和 `tools/make_patch.py`。
- 游戏有反篡改自检：每进一个房间随机抽查一段脚本，源码里换行超过 1 个就清空所有存档；10168 号脚本存在也会给存档打标记；`txt_cartel` 445~451 行是反作弊特征串。所以补丁新增的脚本压成一行、放进 5093 以下的空位，脚本总数不变，那几行也不翻译（见 `make_patch.py` 的 `check_anti_tamper`）。
- 中文按 GBK 存储。汉字之间插了空格，好让游戏原有的按空格断行逻辑继续工作；这种空格在两个汉字之间不占宽度。
- 对话框每行原来最多 40 字节，中文放宽到 120。原版切行有条隐藏分支：一段话除了最后一个字都放得下时，会带个空格递归调自己，可这时对话框状态已经占上，递归直接退出、状态没人清，就成了空框挂着、后面的对话全被跳过。原版因为 40 字节的上限碰不到，放宽后就会碰到，所以补丁把这条分支改成只在剩下的字整段放得下时才走（见 `make_patch.py` 的 `FIXED_SUBS`）。
- 存档里存着当时的游戏语言，读档会把语言改回去。补丁改成读档时用标题画面选的语言：去读 `data\text\config.ini`（`patch/gml/zh_cfg_lang.gml`），而不是沿用内存里的语言，因为游戏里按 F6 或从菜单读档会重启游戏、跳过标题画面，这时语言是游戏默认的西语。
